# Reproducibility

## Requirements

- Linux x86_64.
- Docker with Compose v2 for the canonical run.
- About 3 GB free disk for upstream checkouts, Node modules, the image, and
  generated artifacts.
- No LLM API key is required.
- Network access for the first fetch/build.

Host-only runs additionally need Node 24.22.x (or `npx node@24.22.1`), npm,
Python 3, and optionally WABT 1.0.42 and TShark.

## Pinned inputs

`artifact/scripts/fetch_upstream.sh` clones:

- `https://github.com/qybaihe/bla` at
  `9c41bb53b040797e098954c4007425981f3a7a6b` (`bla-agents 3.2.5`)
- `https://github.com/morluto/rea` at
  `d74549e495c58eb4a560279fd9f05508401ea0a0` (`rea-agents 6.9.0`)

The script verifies the commit after checkout. `results/env.container.json`
records the canonical Node, npm, TShark, WABT, and Python package versions;
host-only `results/env.json` is non-canonical and ignored.

## One-command canonical run

```bash
cd artifact
docker compose build study
docker compose run --rm study
```

`docker compose run` executes `scripts/docker_run.sh` inside the container.
That script:

1. Marks mounted Git directories safe.
2. Fetches the pinned upstreams.
3. Runs `npm ci` and builds BLA and REA if `node_modules` is absent.
4. Regenerates fixtures.
5. Runs baseline, main matrix, variants, intensity sweep, and equivalence
   checks.
6. Runs model load checks, PCAP probes, SQLite probes, MCP probes, and three
   repeated token runs.
7. Rebuilds `summary.json`, `summary.md`, `statistics.json`, and
   `tokenizer_equivalence.json`.
8. Writes `env.container.json` and regenerates the four figures.

Expect several minutes on a warm image; the first build downloads Debian
packages, Node modules, WABT, and Python wheels. The run is CPU-bound during
BLA protection and REA analysis; it does not require a GPU.

## Host run (non-canonical)

```bash
cd artifact
bash scripts/fetch_upstream.sh
(cd upstream/bla && npm ci && npm run build)
(cd upstream/rea && npm ci && npm run build:cached)
node scripts/make_fixtures.mjs
node scripts/run_baseline.mjs
node scripts/run_matrix.mjs
node scripts/run_variants.mjs
node scripts/intensity_sweep.mjs
node scripts/verify_equivalence.mjs
python3 scripts/check_models.py > results/model_equivalence.json
node scripts/pcap_probe.mjs
node scripts/sqlite_probe.mjs
node scripts/mcp_probe.mjs js-unprotected "$(pwd)/fixtures/src/app"
node scripts/mcp_probe.mjs js-protected "$(pwd)/fixtures/protected/js-app"
node scripts/mcp_probe.mjs js-unprotected-summary "$(pwd)/fixtures/src/app" analyze_javascript_application summary
node scripts/mcp_probe.mjs js-protected-summary "$(pwd)/fixtures/protected/js-app" analyze_javascript_application summary
node scripts/replications.mjs
node scripts/summarize.mjs
python3 scripts/tokenizer_check.py > results/tokenizer_equivalence.json
node scripts/statistics.mjs
node scripts/provenance.mjs
node scripts/figures.mjs
```

Host scripts use `npx -y node@24.22.1` unless `NODE_BIN` is set. Host results
are overwritten by the Docker run; use a separate checkout or copy
`results/` before switching if both are needed.

## Outputs

- `results/summary.json`, `results/summary.md`
- `results/statistics.json`
- `results/tokenizer_equivalence.json`
- `results/pcap.json`
- `results/sqlite_probe.json`
- `results/model_equivalence.json`
- `results/intensity_equivalence.json`
- `results/replications.json`
- `results/env.container.json` (canonical; host-only `env.json` is ignored)

Large, git-ignored outputs:

- `results/raw/` (full REA evidence per case)
- `results/variants/` (ASAR/WASM variant evidence)
- `results/mcp/` (MCP request/response transcripts)
- `results/pcap/` (TShark JSON dumps)
- `results/equivalence.json`
- `results/matrix.json`

The large files are regenerated by the pipeline. Total results size is about
420 MB, dominated by WASM, ASAR, PCAP, and MCP transcripts.

## Reproducing the claim audit

```bash
node artifact/scripts/extract_bla_evidence.mjs
```

This reads the pinned BLA README, benchmark code, verifier, benchmark outputs,
and `docs/redteam/empirical-rea-validation.json`, then writes:

- `data/bla-self-validation.json`
- `data/bla-benchmark-factors.json`
- `data/bla-verify-factors.json`
- `data/bla-evidence.json`

The script fails loudly if a required source file or expected field is
missing. It does not call live REA; live numbers come from the main pipeline.

## Figures

```bash
cd artifact
node scripts/figures.mjs
```

Writes SVG to `../figures/`. PNG conversion uses ImageMagick:

```bash
cd figures
for f in *.svg; do convert -density 130 "$f" "${f%.svg}.png"; done
```

## Determinism checks

`results/replications.json` contains three repeated token-count runs for JS,
WASM, and EVM. Token counts are deterministic; wall time varies. The
`make_fixtures.mjs` script uses fixed seeds and deterministic ZIP headers, so
fixture hashes should match across runs except where the OS timestamps leak
into a container format. `provenance.mjs` records fixture SHA-256 hashes;
compare those first if a result drifts.

## Known gotchas

- Host Node 24.15 is too old for REA; use `npx node@24.22.1` or the container.
- Host WABT 1.0.36 is too old; use 1.0.42 or the container.
- Host TShark may be absent; PCAP results require the container or a TShark
  install.
- `verify_equivalence.mjs` needs `TMPDIR` to be writable; the container sets
  it implicitly, and host runs use the system temp directory.
- `docker compose run` mounts the repository at `/work`; absolute paths in
  evidence differ from host paths, which changes token counts slightly.
