The 30-second version

What this study found

Three findings, each checkable in the repository. No single-number hero story, no hidden assumptions.

FINDING 01

BLA's own claim surfaces disagree.

639.5× vs 1,067.3×

The README reports ~639.5× token amplification. The same-commit benchmark reports 1,067.3×. Seven of fourteen per-case factors differ, and the verifier marks runtime equivalence as not-tested while still returning overallPassed: true.

FINDING 02

The live outcome is conditional.

4 amplified · 3 neutral · 5 refused

At the bankrupt preset, JavaScript, WASM, EVM, and PCAP amplify strongly. SQLite, PTX, and ELF are neutral. ASAR, safetensors, GGUF, BEAM, and PYC are refused. One documented ASAR override converts a refusal into 718.14×.

FINDING 03

The published factor does not predict the measured factor.

r = 0.039 · slope = 0.018

Across the eight successful CLI cases, log10 Pearson correlation is 0.039 and the log-log slope is 0.018. The claimed geometric mean is 1,003.24×; the measured geometric mean is 36.38×. The sample is small, but the spread is not.

Read this if you only remember one sentence

Budget traps are real, but they are query-shaped, fixture-dependent, and sometimes convert a refusal into a larger bill. A claim of the form “format X costs N×” is under-specified without the intensity, command, transport, output detail, budget, and ABI check.

Zero jargon

What is a budget trap?

If you have never thought about reverse engineering or token budgets, start here. Every term is explained the first time it appears.

1. An artifact ships

A program, model, database, or packet capture. It contains code and data that someone may want to inspect.

↓

2. A protector adds decoys

BLA inserts fake structures, oversized metadata, and resource traps. The goal is to make automated analysis expensive without breaking normal execution.

↓

3. An analyzer spends a budget

REA reads the artifact and returns evidence. Every output consumes tokens: the unit an AI agent pays in context, time, and money.

↓

4. The bill depends on the path

Summary vs full JSON, narrow vs broad fields, CLI vs MCP, default vs raised budget. The same protected file can cost 1.67× or 2,077×.

Why business readers should care

Security vendors, platform teams, and investors increasingly hear claims like “our protection raises reverse-engineering cost by 1,000×.” This study shows why that sentence is not enough to make a procurement or investment decision. The useful question is not “what is the factor?” but “under which analyzer, transport, query, and budget?”

Why researchers should care

The repository is a reproducible case study in evaluation methodology: pinned upstreams, independent fixtures, a retrospective protocol, exact numbers, and a clear separation between a structural self-check and a runtime-equivalence claim. It is designed to be attacked, replicated, and extended.

One important distinction

A refusal is not automatically a defender win. It can be a security boundary, a usability failure, or a signal for the analyst to switch tools. This study reports refusals separately instead of averaging them into an amplification factor.

🌱 Beginner guide

Read this and you are a professional

Six levels from “what is reverse engineering?” to “how do I verify the claim myself?” Each level has a checkpoint. No prior security background required.

01

What is reverse engineering?

Reverse engineering is the work of understanding what a program does when you do not have its source code. A security analyst may do it to find a vulnerability; a competitor may do it to understand a product; a platform may do it to check whether a vendor's protection claim is true.

artifactanalyzerevidence
Checkpoint: why can reverse engineering be automated?

Because much of the work is pattern recognition over structured outputs: disassembly, metadata, strings, schemas, and protocol fields. An AI agent can read those outputs and decide what to inspect next — which is exactly why token cost becomes a security property.

02

What is a budget trap?

A budget trap is an artifact designed so that automated analysis spends more tokens, time, or memory than the information is worth. It does not necessarily stop the analyst. It makes the analyst pay. BLA's traps include decoy structures, oversized metadata, and resource limits.

decoytoken budgetamplification
Checkpoint: is a refusal the same as a high bill?

No. A refusal is an error payload; a high bill is a successful analysis that returns a lot of evidence. The study reports them separately because averaging them hides the difference between “blocked” and “expensive.”

03

What did this study test?

It pinned BLA 3.2.5 and REA 6.9.0 at exact commits, built 12 small fixtures from source, protected them at four intensities, and ran live REA on each. It also audited BLA's own README, benchmark, verifier, and live-REA validation at the same commit.

pinned commitfixtureprotocol
Checkpoint: why use independent fixtures instead of BLA's showcase?

To test external validity. Replaying BLA's own fixtures would only show that BLA's demonstration works on BLA's demonstration. Independent fixtures ask whether the published behavior survives artifacts BLA did not design.

04

What did it find?

BLA's claim surfaces disagree (639.5× vs 1,067.3×; 7 of 14 factors differ). The live outcome is conditional (4 amplified, 3 neutral, 5 refused). The published factor does not predict the measured factor (log10 r = 0.039, slope = 0.018).

claim auditoutcomecorrelation
Checkpoint: does “no correlation” mean BLA is ineffective?

No. It means the published per-format factor is not a portable predictor in this sample. BLA's traps do produce large effects on some paths. The correct conclusion is conditional, not binary.

05

Why is the result subtle?

Because the same protected artifact can cost 1.67× through one transport and 2,077× through another; 1.82× through a narrow PCAP query and 275.4× through a payload query; 789 error tokens at a default cap and 47.2M success tokens after a documented override. The path is part of the result.

query shapetransportoverride
Checkpoint: what is the minimum honest way to report a factor?

State the protector intensity, the analyzer command, the transport, the output detail, the relevant budget, and the ABI/functional check. Without those, two “10×” claims may not be comparable.

06

How do I verify it?

Clone the repository, run the canonical Docker pipeline, and compare the generated artifact/results/summary.json with the tables on this page. The pipeline pins BLA, REA, Node, TShark, WABT, and Python. If a number changes, the diff is the finding.

Start with the claim audit: do the README and benchmark factors agree? Then check the live outcomes, then the correlation. Each layer answers a different question.

Questions

FAQ and glossary

The objections a careful reader should raise, answered directly.

Is this an attack on BLA?

No. It is an audit of public claims at pinned commits. BLA is not modified or redistributed; upstream code is cloned at build time. The finding is about the portability of a published factor, not about whether the traps work at all.

Does “no correlation” mean BLA is ineffective?

No. It means the published per-format factor is not a portable predictor in this sample. The traps do produce large effects on some paths: JavaScript 111.04×, WASM 2,077.21×, EVM 978.6×, and PCAP 14.37× at the bankrupt preset.

Are these dollar costs?

No. The study measures tokens with REA's own counter. A dollar conversion depends on provider pricing, caching, and retries, so it is not claimed. The cost ratio is a separate, explicit calculation.

Why only 15 cases?

The design prioritizes independent fixtures and controlled paths over a large convenience sample. The sample is small, the bootstrap interval is wide, and the repository is built to be extended. The correct reading is “the published factor is not portable here,” not “the true correlation is zero everywhere.”

Why no LLM API keys?

The study measures analyzer output cost, not model behavior. Removing the model removes a confounder and makes the run reproducible. The token counter is the measurement instrument; the model is a separate layer.

What is the strongest counterargument?

A larger fixture set, different analyzer settings, or a different query mix could change the correlation. That is why the protocol records deviations and why the raw JSON is published. The repository is designed to be attacked on exactly those grounds.

Is it safe to run?

It executes pinned upstream code and builds local fixtures. Use the documented Docker path, review THREAT-MODEL.md, and treat the artifacts as untrusted input. No API key is required.

Artifact

The file or package being analyzed: a program, model, database, or packet capture.

Protector

The tool that transforms an artifact to raise the cost of analysis. BLA is the protector studied here.

Analyzer

The tool that reads the artifact and returns evidence. REA is the analyzer studied here.

Token

The unit an AI agent pays in context, time, and money. The study uses REA's token counter, not a dollar invoice.

Budget trap

An artifact designed so that automated analysis spends more tokens, time, or memory than the information is worth.

Amplification

The ratio of protected-analysis tokens to baseline-analysis tokens. It is reported only for successful analyses.

Refusal

An error payload returned instead of analysis. It is reported separately because a refusal is not the same as a high bill.

Transport

How the evidence reaches the consumer: CLI full JSON, MCP summary, or MCP complete. The same artifact can cost 1.67× or 2,077× depending on the transport and query.

Query shape

Which fields the analyzer returns. A narrow frame.number query is 1.82×; a tcp.payload query is 275.4× on the same PCAP.

ABI

The interface a compiled module exposes to its host. Preserving it is why the WASM result is both large and functionally meaningful.

Fixture

A small, independently authored artifact built from source for a controlled test. Twelve fixtures drive the live runs.

MCP

Model Context Protocol, a transport between an analyzer and an AI agent. Its stdio budget can refuse a response before the model sees it.
